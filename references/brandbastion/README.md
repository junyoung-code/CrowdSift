## 사용 원칙

- 이 파일들은 CrowdSift의 정보 밀도, 여백, 타이포그래피 위계, 카드 비율과 섹션 리듬을 판단하는 시각 자료다.
- CrowdSift의 실제 기능, 한국어 문구와 데이터 구조를 우선한다.
- BrandBastion의 로고, 문구, 고객사 로고, 성과 수치, 사진, 일러스트와 기타 자산을 제품에 복사하지 않는다.
- 원본 사이트의 소스 코드, DOM 구조나 화면을 그대로 복제하지 않는다.
- 첨부 자료에는 모바일 화면이 없으므로 모바일 레이아웃은 별도로 설계하고 검증한다.
