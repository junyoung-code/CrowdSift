# CrowdSift UI Visual References

## Selected direction

- **File:** `2026-07-28-conversation-workspace.png`
- **Selected:** 2026-07-28
- **Direction:** 대화 중심 워크스페이스

이 이미지는 CrowdSift Comment Inbox의 정보 구조와 시각 위계를 정하기 위한 Product Design 목업이다.

생성된 이미지 파일은 `1487 × 1058`이지만 구현 기준 viewport는 `1440 × 1024`다. 픽셀을 그대로 복제하지 않고 동일한 정보 위계가 자연스럽게 맞도록 재배치한다.

구현 시 유지할 요소:

- 얇은 아이콘 내비게이션
- 목록보다 넓은 실제 댓글 스레드
- 스레드 아래에 붙는 답글 작성기
- 접을 수 있는 분석 요약
- `안전 / 주의 / 위험`의 아이콘·텍스트 병행
- 유해 출처 댓글 기본 숨김
- 답글 게시 전 명시적 확인

이미지 안의 프로필, 영상, 댓글, 수치와 로고 형태는 실제 연결 데이터나 완성된 브랜드 자산이 아니다. 구현에서 이 값을 실제 YouTube 데이터처럼 사용하거나 픽셀 단위로 복제하지 않는다.
