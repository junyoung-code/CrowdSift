## 관찰한 것

### 목록 화면

- 상단 컨트롤: `게시됨` 상태 필터 / `관련성순` 정렬 / `검색` / `필터`
- 행 구성: 작성자 · 작성 시각 · 댓글 본문 · `답글` 버튼 · `답글 N개` 펼치기 · 좋아요 · 싫어요 · 하트 · 더보기
- 우측에 해당 댓글이 달린 영상 썸네일과 개수
- 왼쪽 체크박스로 다중 선택 가능

### 의미 기반 검색 (주목할 부분)

검색 패널이 키워드 검색이 아니라 **댓글 유형을 고르는 방식**이다.

제시하는 예시 항목:

- 일반적인 칭찬
- 흥미와 열의
- 민감한 주제
  - 부정적인 의견
  - 욕설

여기에 더해 자유 입력란이 있다 — `또는 찾고 있는 댓글 유형 설명하기` (100자 제한).

패널 하단 고지: *"지난 90일 동안의 댓글을 검색합니다. 경우에 따라 품질과 정확성이 다를 수 있습니다."*

### 행 단위 동작

더보기 메뉴에 세 가지가 있다.

- 비슷한 댓글 찾기
- 수정
- 삭제

## 우리 제품과의 관계

### 겹치는 부분

YouTube Studio는 이미 의미 기반으로 댓글을 분류해 보여준다. `부정적인 의견`, `욕설` 같은
축은 우리의 `주의` 판정과 대상이 상당히 겹친다. "악성 댓글을 골라내는 것"만으로는
차별점이 되지 않는다는 뜻이다.

### 겹치지 않는 부분

관찰한 범위에서 YouTube Studio가 하지 않는 것:

- **원문을 감추지 않는다.** 부정적인 의견으로 필터링해도 크리에이터는 원문을 그대로 읽게 된다.
  악플을 읽는 정서적 피해를 줄여주지는 않는다.
- **순화해서 전달하지 않는다.** 거친 표현 속의 실행 가능한 피드백만 뽑아 주는 기능이 없다.
- **위험도를 등급으로 나누지 않는다.** 협박·스토킹처럼 즉시 대응이 필요한 것과 단순 욕설이
  같은 목록에 섞여 있다.
- **증거를 보관하지 않는다.** 삭제하면 원문이 사라진다. 신고나 법적 대응에 쓸 기록이 남지 않는다.
- **채널별로 기준을 조정할 수 없다.** 채널에서 긍정적으로 쓰이는 은어나 팬 밈을 예외로
  등록하는 수단이 없다.
- **검색 범위가 90일로 제한된다.**

### 시사점

우리 페르소나의 핵심 욕구는 *"상처받지 않으면서도 시청자의 반응으로 콘텐츠를 개선하고 싶다"*
였다. YouTube Studio는 **찾아주기**까지는 하지만 **읽지 않게 해주지는** 않는다.

원문 숨김, 순화 전달, 위험 등급 분리, 증거 보관이 우리가 서 있을 자리다.
