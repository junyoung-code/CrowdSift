# CommentHawk Codex 작업 가이드

CommentHawk를 실제 데이터 기반으로 개발하기 위한 순서형 가이드다. 설명은 한국어로 작성했고, Codex에 그대로 입력하는 부분만 영어 프롬프트로 제공한다.

문서는 번호 순서대로 사용한다. 각 프롬프트를 입력하기 전에 현재 저장소와 `docs/product-context.md`를 다시 확인하며, 이전 단계가 실제로 완료되지 않았다면 다음 단계로 넘어가지 않는다.

1. [Codex에 넣기 전에 준비할 자료](./01-codex에-넣기-전에-준비할-자료.md) - 제품 기준 문서, 시각 자료와 비밀값 준비 범위를 확인한다.
2. [먼저 설치하면 좋은 Codex용 기능](./02-먼저-설치하면-좋은-codex용-기능.md) - 선택적인 Codex 개발 도구와 설치 원칙을 확인한다.
3. [실제로 사용할 GitHub 저장소](./03-실제로-사용할-github-저장소.md) - 필요한 공식 라이브러리와 도입 시점을 정한다.
4. [첫 번째 Codex Ask 모드 프롬프트](./04-첫-번째-codex-ask-모드-프롬프트.md) - 구현 전에 첫 실제 수직 슬라이스의 계획만 작성한다.
5. [승인된 계획 실행 프롬프트](./05-승인된-계획-실행-프롬프트.md) - 승인된 범위의 기반 구조를 구현한다.
6. [YouTube 연결과 댓글 가져오기 프롬프트](./06-youtube-연결과-댓글-가져오기-프롬프트.md) - 실제 계정, 영상과 댓글 데이터를 연결한다.
7. [AI 분류와 개인화·Comment Inbox 프롬프트](./07-ai-분류와-개인화-comment-inbox-프롬프트.md) - 실제 댓글 분석, 개인화와 Inbox 표시를 완성한다.
8. [가장 중요한 수정점](./08-가장-중요한-수정점.md) - 모든 단계에서 지켜야 할 제품·데이터·안전 원칙을 점검한다.
