# 테스트용 유튜브 환경 — 영상·댓글 배치 계획 v0.3

분류 기준 v0.1(안전/주의/위험)을 실제 서비스 흐름에서 검증하기 위한 테스트 데이터.
댓글 문구는 기획서의 대표 댓글 예시를 뼈대로 하고, 영상 주제와 대화 흐름에 맞게 확장했다.

> **이 문서의 등급은 정답이 아니다.**
> 표에 적힌 기대 등급은 기준 문서를 읽고 붙인 것이며, 팀이 검토해 합의한 값이 아니다.
> 파이프라인이 수집·분류·저장까지 실제로 도는지 확인하는 것이 이 묶음의 용도다.
> 결과가 기대와 다르면 기록은 하되 정확도 수치로는 쓰지 않는다. 성능 측정에 쓸 정답
> 데이터는 별도 절차로 만든다.

- 총 90개 = 안전 26 / 주의 26 / 위험 26 / 맥락 의존 12
- 영상 3개 × 30개 (최상위 댓글 66 + **답글 24**)
- **각 영상의 표는 게시 순서다.** 위에서부터 차례로 올리면 답글이 항상 부모 뒤에 온다.
- **맥락 의존 12개는 정답 등급을 확정하지 않는다.** 팀 라벨링이 갈리는지 보는 용도.

> **v0.3에서 달라진 점**
> 답글이 부모마다 1개씩 고르게 붙어 있던 것을 **스레드 크기를 섞도록** 바꿨다. 실제 댓글창은 논란되는 댓글 하나에 답글이 몰리고 나머지는 답글이 없다.
>
> 크기를 섞어야만 검증되는 것이 있다. 한 스레드 안에 안전·주의·위험이 함께 있을 때 **전체를 숨기는지 해당 답글만 숨기는지**, 악플에 **동조가 누적될 때** 개별 판단으로 충분한지는 답글이 하나뿐이면 드러나지 않는다.

## 스레드 구조

영상마다 같은 모양으로 구성했다.

```
큰 스레드 (답글 4)   ← 논쟁이 붙은 댓글. 안전·주의·위험이 한 스레드에 섞임
중간 스레드 (답글 2)
작은 스레드 (답글 1) × 2
단독 댓글 × 18
```

| 영상 | 큰 스레드 | 성격 |
|---|---|---|
| A | A05 (🔴 위험) | 악플에 **동조 2 + 반대 2**가 몰림 |
| B | B05 (🟢 안전) | 평범한 질문이 **위치 추적으로 번짐** |
| C | C05 (🟡 주의) | 콘텐츠 비판이 **인신공격으로 번짐** |

## 게시 전 확인

1. **영상은 "일부 공개(링크 있는 사람만)"로 업로드한다.**
   위험 댓글이 완전 공개 영상에 달리면 계정 제재 위험이 있다.
2. **표 순서대로 올린다.** `↳` 표시가 있는 줄은 지정된 댓글의 **답글**이다. 유튜브에서 해당 댓글의 `답글` 버튼을 눌러 달아야 한다.
3. **유튜브 답글은 2단까지만 지원한다.**
   표에 `↳ B06`처럼 답글에 다는 답글이 있는데, 유튜브는 이것을 같은 층으로 펼치고 `@사용자명`을 앞에 붙인다. 그대로 두면 된다 — **대화가 평평해졌을 때도 흐름을 따라가는지**가 확인 대상이다.
4. **게시 후 시크릿 창으로 영상을 열어 개수를 센다.**
   유튜브가 일부 댓글을 자동 보류하면 서비스로 넘어오지 않는다. 30개 달았는데 26개만 들어오는 상황을 미리 잡아야 한다.
5. **사라진 댓글은 ID에 표시해 둔다.** 결과를 대조할 때 누락과 오분류를 구분해야 한다.
6. **가져올 댓글 개수는 넉넉히 잡는다.** 부모와 답글을 합쳐서 세므로, 영상당 30개를 다 받으려면 상한을 30보다 크게 설정해야 한다.

## 검증 포인트 ②: 답글 맥락

### ★ 최우선 — A06 ↔ A11

```
A05  너 같은 인간은 유튜브 하면 안 된다   (위험)
 └ A06  ㄹㅇ 인정                       → 악플 동조

A10  영상이 조금 길어서 집중력이 떨어졌어요  (안전)
 └ A11  ㄹㅇ 인정                       → 단순 공감
```

답글 텍스트가 **한 글자도 다르지 않다.** 부모 댓글로만 구분된다.

| 결과 | 해석 |
|---|---|
| 둘 다 안전 | 부모 맥락을 사실상 무시하고 있음 |
| 둘 다 주의·위험 | 부모 등급이 무조건 전이됨 → A07·A09·B11·C09 같은 선의의 답글이 억울하게 걸림 |
| A06만 올라감 | 맥락이 제대로 작동 |

### 검증 포인트 ③: 스레드 전체 판정

큰 스레드 3개는 **한 스레드 안에 등급이 섞여 있다.** 이게 이번 버전의 핵심이다.

```
A05 🔴 너 같은 인간은 유튜브 하면 안 된다
 ├ A06 🔴 ㄹㅇ 인정              (동조)
 ├ A07 🟢 이런 댓글 좀 그만 다세요   (반대)
 ├ A08 🔴 ㅇㅈ 볼 때마다 답답했음    (동조 누적)
 └ A09 🟢 신고했습니다             (반대)

B05 🟢 어느 카페인지 알 수 있을까요?
 ├ B06 🔴 그러게 어디 사는지 궁금하네
 │   ├ B07 🟢 이런 거 물어보지 마세요 진짜
 │   └ B08 🔴 저번에 그 동네에서 봤는데
 └ B09 🟡 알려주면 큰일 나냐

C05 🟡 게임 진짜 못하네 답답해서 못 보겠다
 ├ C06 ⚪ 또 게임 못하네ㅋㅋ         (팬 밈)
 └ C07 🔴 머리가 나쁘니까 게임도 못하지
     ├ C08 🔴 ㄹㅇ 팩트             (동조)
     └ C09 🟢 그건 좀 심하다        (반대)
```

확인할 것:

| 질문 | 관련 ID |
|---|---|
| 위험 답글이 섞였다고 스레드 **전체**를 숨기는가, 그 답글만 숨기는가 | A05 스레드 전체 |
| 악플을 **말리는 사람**이 같이 묻히지 않는가 | A07, A09, B07, C09 |
| 동조가 **누적**될 때 개별 판단으로 충분한가 | A06 + A08, C08 |
| 안전한 부모로 시작한 스레드가 **위험으로 번지는 것**을 잡는가 | B05 → B06 → B08 |
| 주의 스레드가 답글에서 **위험으로 올라갈 때** 부모 등급도 올리는가 | C05 → C07 |
| 한 스레드에 팬 밈(C06)과 인신공격(C07)이 **같이** 있을 때 | C05 스레드 |

## 분석 실행 후 확인할 것

점수를 매기는 자리가 아니다. 아래는 **눈으로 확인할 것**이며, 기대와 다르면 왜 그런지를
적어 두는 것이 목적이다.

**동작 확인** — 기대 등급과 무관하게 참·거짓이 분명한 항목

1. **주의 + 피드백 없음 8개에 순화 댓글이 생성되었는가** — 생성되면 안 된다.
2. **위험으로 나온 댓글에 순화 댓글이 생성되었는가** — 생성되면 안 된다.
3. **위험으로 나온 댓글의 원문이 기본 숨김 상태인가**
4. **큰 스레드 3개가 대화 형태로 묶여 보이는가** — 인박스 화면에서 읽히는지 본다.
5. **90개가 누락 없이 들어왔는가** — 유튜브 자동 보류로 사라진 건과 구분한다.

**관찰** — 기준을 다듬을 재료. 맞고 틀림이 아니라 차이를 본다

6. 기대와 다르게 나온 건이 어디에 몰려 있는가
7. 하드 위험 5건(협박·스토킹·개인정보 계열)이 어떻게 나왔는가
8. 답글 24개가 부모 댓글에 따라 갈렸는가 — A06 ↔ A11이 서로 다르게 나오는지 본다
9. 맥락 의존 12개가 어떤 등급으로 나왔는가

### 기록 방식

## 이 테스트 후 기준 v1.0에 추가해야 할 항목

답글 규정이 v0.1에 없으므로, 결과를 보고 다음을 정한다.

- [ ] 답글의 등급을 부모와 독립적으로 매기는가, 부모 등급을 하한선으로 삼는가
- [ ] 부모가 위험일 때 선의의 답글(A07, A09, B07, B11, C09)을 어떻게 노출하는가
- [ ] 스레드 안에 위험 답글이 하나 있으면 스레드 전체를 숨기는가, 그 답글만 숨기는가

- [ ] 주의 등급 답글을 순화할 때 대화 흐름이 깨지는 문제를 어떻게 다루는가
- [ ] `ㅋㅋㅋㅋㅋ`, `ㄹㅇ`처럼 의미가 비어 있는 답글의 기본 처리
