## 데이터 해석

확정된 등급 교정만 수정한다. 재검수 필요 10건은 기존 평가를 원본에 보존하고 새 비교에서는 제외한다. 이전 미분류 3건을 포함한 새 분모는 98건이다. 사람 중간 분석을 대신 작성하지 않는다. 동일한 수정 후 정답에 이전/새 결과를 대입한 수치와 원래 정답 기준 수치를 모두 보고한다.

프롬프트에 사용한 개발 사례를 포함하므로 정확도 95%나 독립 평가 통과를 주장하지 않는다. 실제 API 실패를 HOLD로 변환하지 않는다. 운영 전환은 수행하지 않는다.

## 실제 결과

- 같은 수정 후 평가 기준: 이전 88/98 (89.8%) → 이번 92/98 (93.9%), +4.1%p.
- 원래 108건 등급 기준: 이전 86/108 (79.6%) → 이번 91/108 (84.3%). 두 지표를 혼용하지 않는다.
- 비용: 실측 토큰에 단가를 적용하면 $0.085171 → $0.1124578 (+32.0%). 입력 221,339 / 출력 56,825, 기록된 호출 135회. 청구액은 아니며 캐시 할인·미집계 전송 재시도를 반영하지 않는다.
- 4번 CAUTION / creator 조롱, 51번 RISK / creator 조롱, 66번 HOLD, 95번 SAFE / other_commenter 외모 공격. 107·108번 CAUTION, 109·111번 RISK.
- 분석 실패 59번: 원문의 '익숙지는'을 '익숙하지는'으로 고쳐 evidence를 출력하여 구조 검증 탈락. 자동 보정이나 재시도로 실패를 숨기지 않았다.
- 재작성 실패 7·96번은 CAUTION 유지, 미검증 재작성은 비노출.
- 남은 등급 불일치: 42·56·70·86·101번. 특히 70번 외모 칭찬 과잉 해석, 101번 타인 대상 식별 실패는 후속 개선 대상이다.
- 96번은 명시되지 않은 음식 중심 화면 선호를 claim으로 추출한 문제가 남았다. 재작성 검증도 이 추가 의미를 잡지 못했지만 강도 보존에서 탈락해 최종 전달문은 노출되지 않았다. 의미 분석·검증 정확도 완성을 주장하지 않는다.
- 구현과 실행은 완료했으며 독립 평가·운영 전환은 하지 않았다.
